## 1. 故事和通关目标

**开场**：1502 年 2 月 21 日，葡萄牙里斯本。主角里昂·佛朗哥（Leon Franco）出身没落的航海世家。父亲出海一去杳无音讯，一年后，父亲的大副被冲上岸，带回了父亲的遗书。里昂决定接过父亲的事业出海闯荡，重振家族。【代码确认：开场剧情文字】

**通关目标**：
1. 在葡萄牙一路升爵，从无爵位做到 **公爵**。
2. 当上公爵后，国王会交给你最终任务：**从海盗手里救出被掳走的克莉丝汀娜公主**。
3. 把公主平安带回里斯本见国王，进入结局。

**时间限制**：航海生涯大约 **20 年**，也就是到 1522 年左右。超时会进入"渡过了二十年的航海生涯，身体越来越虚弱……还没有实现愿望就踏上了天国之路"的失败结局。【代码确认：结局文字】

**名望**：游戏的"分数"，影响国王是否召见你。名望上限是 **50000**。【代码确认】

## 4. 主线流程（按阶段）

### 阶段 0：开局准备（1502 年）

- 初始资金 **1000 金币**，一艘小船，船员 20 人。【代码确认：存档初始值】
- 先去 **港口 → 补给**，给船装满粮食和水。
- 去 **酒馆** 招满船员，最好再招一名航海士。
- 第一次出海建议只在 **伊比利亚半岛和地中海西部** 跑短途，熟悉航海和补给。

### 阶段 1：攒第一桶金（约 1502–1504 年）

- 目标：攒到 **1 万金币以上**，换一艘载货量大的船。
- 跑短途贸易，路线见 [第 9 节](#9-赚钱路线)。
- 每到一个新港口，名望都会上涨（发现港口）。
- 钱多了可以存进里斯本皇宫的账户，这样战败也丢不了。

### 阶段 2：提升名望，等国王召见

名望来源：【网上攻略】
- **在交易所投资**：每次 1000 金币。把一个港口争取成葡萄牙的同盟港，能得约 400 名望。
- **击败海盗或敌国舰队**。
- **完成商人、行会的委托**。

> **发现新港口不加你的名望**，加的是舰队里各位船长、航海士的经验值，港口越大加得越多。【代码确认】另外，"发现港口"只在船航行经过港口旁边时才会触发；用修改器瞬移过去再直接进港，不会提示，也不算发现。

#### 国王召见的名望门槛【代码确认】

国王召见你的条件：**名望 > (当前爵位 + 1)² × 400**（必须大于，正好相等不算）。

| 当前爵位 | 名望要超过 |
|---|---|
| 0 无 | 400 |
| 1 侍从 | 1600 |
| 2 乡绅 | 3600 |
| 3 爵士 | 6400 |
| 4 从男爵 | 10000 |
| 5 男爵 | 14400 |
| 6 子爵 | 19600 |
| 7 伯爵 | 25600 |
| 8 侯爵 | 32400 |
| 9 公爵（最终任务：营救公主） | 40000 |

- 名望上限是 50000。
- **检查时机**：只在 **海上航行时**，每过一天有 **5%** 的概率检查一次名望是否达标。所以名望够了以后，平均还要在海上开 20 天左右才会被召见。在港口里待着不会触发。
- 手上已经有任务没完成时，国王不会派新任务。
- 名望不够门槛时，游戏偶尔会派商人、行会的小委托，不是国王的任务。
- 被召见后，酒馆里会有人说"国王正等你呢"，这时去王宫，卫兵会说"陛下已在等候您了"。

#### 王宫进门规则【代码确认】

- **爵位是 0（无爵位）**：没被召见时，卫兵说"皇宫严禁平民入内"，进不去。
- **爵位 1 以上**：随时可以进王宫，但国王派不派任务，看上面的名望门槛。

> 拒绝委托、半途放弃委托都会扣名望。放弃国王任务时，名望会减少当前值的 10%–20%（随机）。【代码确认】

### 阶段 3：国王任务循环，逐级升爵（约 1503–1515 年）

- 每完成一个国王任务，爵位 **+1**。【代码确认】
- 爵位共 10 档（编号 0–9）：

| 编号 | 爵位 | 编号 | 爵位 |
|---|---|---|---|
| 0 | 无 | 5 | 男爵 |
| 1 | 侍从 | 6 | 子爵 |
| 2 | 乡绅 | 7 | 伯爵 |
| 3 | 爵士 | 8 | 侯爵 |
| 4 | 从男爵 | 9 | **公爵** |

- **奖金** =（3~5 的随机数）× 当前爵位 × 1000 金币，存进你在皇宫的账户。【代码确认】
- 也就是说，爵位越高，任务奖金越多。比如升到伯爵（7）时，一次奖金是 21000–35000。
- 从无爵位到公爵，一共要完成 **9 个任务**。

### 阶段 4：追求公主（和阶段 3 同时进行）

做完第一个国王任务后，就可以去王宫楼上见公主。详见 [第 6 节](#6-追求公主)。

### 阶段 5：成为公爵 → 最终任务

爵位到 9（公爵）时，国王派出的任务固定为 **营救公主**。【代码确认：爵位为 9 时，任务固定为营救公主】详见 [第 7 节](#7-最终任务营救克莉丝汀娜公主)。

### 阶段 6：结局

把公主带回里斯本见国王，进入结局。详见 [第 8 节](#8-结局)。

## 5. 国王的五类任务

【代码确认：任务对白来自游戏文本；按爵位选任务类型的规则来自反编译】

| 类型 | 国王怎么说 | 你要做什么 |
|---|---|---|
| **寻宝** | "我想找传说中的〇〇，没有人知道它的下落" | 去各地酒馆向女招待打听宝物在哪，找到后带回来。宝物名由形容词加物品组成，比如"狮子的王冠""黄金的圣杯""水晶的竖琴"。 |
| **讨伐** | "最近〇〇在附近骚扰，你是唯一能对付他们的人" | 消灭指定的舰队：西班牙、奥斯曼、商船队或海盗。 |
| **送密信** | "请你给〇〇的国王送去这封密信" | 把信送到指定国家的王宫，在那里选"密会"。全程要保密。 |
| **采购** | "我需要〇〇，但我手里还没有" | 买够指定数量的商品（常见粮食、珊瑚），运回里斯本交给国王。数量不够国王会说"再跑一趟"。 |
| **营救公主** | "公主乘坐的船被袭击，公主被拐走啦" | 最终任务，只在公爵时出现。 |

**任务难度随爵位变化**：
- 游戏内部给前四类任务编了 0–3 号，营救公主是 4 号。
- 无爵位时，固定派 0 号任务。
- 有爵位后，任务编号 =（爵位 − 1）÷ 2 取整，再加 0 或 1 的随机数。爵位越高，编号越大，任务越难。
- 公爵时固定是 4 号：营救公主。
- 0–3 号分别对应上表哪一类，代码里没能直接对上，所以上表的顺序不代表编号。

**接任务和交任务的规矩**：
- 接任务时可以拒绝，但国王会说"太令我失望了"。
- 任务没完成回王宫，国王会问"还去吗"。选放弃会扣名望。
- **接任务前先存档。** 国王可能派你不想做的任务，读档重来即可。【网上攻略】

## 6. 追求公主

- 地点：里斯本王宫楼上。至少完成过一次国王任务后才能见到公主。【网上攻略】
- 三个选项：**谈情说爱 / 赠送鲜花 / 赠送礼物**。【代码确认】
- 礼物是从世界各地买来或找到的宝物，比如珍珠手镯、珊瑚手镯、黄金手镯、戒指、金块、仙女护身符。【代码确认：道具名】
- 好感够了，公主会帮你向国王说情。之后去找大臣，可以领到国王的资助金（"陛下准备援助〇〇枚金币"）。【代码确认：对白；网上攻略：触发方式】
- 公主的好感和结局有关：好感越高，最后越有可能娶到她。

## 7. 最终任务：营救克莉丝汀娜公主

【代码确认：对白】

1. **接任务**：国王说"公主乘坐的船被某些人袭击，公主被他们拐走啦……你要尽快救出公主"。
2. **打听下落**：去各地酒馆选"女招待"。
   - 先问出是谁：她会说"你想救出公主吗？我想好像是被〇〇的〇〇舰队拐骗了"。
   - 再问位置：她会说"听说有人在北纬 X 度、东经 Y 度附近见过他"或"他就在……附近徘徊过"。
   - 只有那支舰队最近经过或正在附近的港口，女招待才会提这件事；没提就换一个港口问。【实际游玩确认】
   - 掳走公主的是 **西班牙、奥斯曼或海盗** 的某位船长，每局可能不同。舰队一直在移动，经纬度只是最近的位置。
3. **截击**：开到那片海域，在海图上看到它的船后开战。开战时你的提督会喊"你就是拐走克莉丝汀娜公主的恶棍吧！为了葡萄牙皇家的名誉把你打入地狱！"。
   - **侦察和战斗都是"选方向"，不是点船**：画面会问"看哪儿？"，按那艘船所在的方向选（键盘模式用方向键，鼠标模式点自己船的那一侧）。【实际游玩确认】
   - 必须离得足够近才能选中它；离远了会提示"附近没有舰队"或选不到。电脑舰队通常比你的船快，追不上时可以用修改器的"瞬移到舰队旁"。
   - 打掉对方的旗舰（提督坐的那艘）就能结束战斗。
   - 建议用 2–3 艘配加农炮的重型加利恩，船员配满。【网上攻略】
4. **救出公主**："克莉丝汀娜公主，感谢上帝，你还平安无事。"
5. **送回里斯本**：船员会提醒"你救了公主，请带她去见国王"。回王宫觐见国王。

## 8. 结局

- **成功结局**：国王感谢你救出公主、消灭了猖獗的海盗，问你想要什么赏赐。你可以选择：
  - 迎娶克莉丝汀娜公主；
  - 要回祖先失去的领地，重振家族；
  - 或者其他回答。不同回答对应不同结局，公主的好感会影响能不能娶到她。【代码确认：结局对白里有这些内容；具体分支条件未逐一确认】
- **失败结局**：
  - 航海 20 年还没完成，年老病逝。【代码确认】
  - 在海上全军覆没，"在大海上断绝了消息"。【代码确认】

## 11. 航海与海战要点

### 航海

海上菜单有：操作 / 调查 / 命令 / 战斗 / 登陆 / 储存进度。【代码确认】

- **粮食和水**：每天消耗。耗尽后船员会死，必须提前在港口补足。远洋前按"天数 × 船员数"多准备一些。
- **资材**：用来在海上修船（"修船"指令）。
- **命令**：配给口粮（减少消耗）、赏赐（提高士气）、人事、辞退。
- **调查**：测量（确认经纬度）、侦察（看附近舰队）。
- **登陆**：可以在陆地上搜索，寻宝任务会用到。
- **夜间不能战斗。**
- **在海上也能存档**（"储存进度"），远洋时多存几次。

### 海战

战斗指令：**移动 / 待机 / 突击 / 炮击 / 逃跑**。【代码确认】

- **炮击**：远距离用火炮打对方船体。
- **突击**：贴近后接舷白刃战，船员多、提督勇气和力量高的一方占优。
- 打赢可以缴获对方的货物和金币（"这就是战利品"）。
- 被俘时可以选 **贿赂** 或 **老实被捕**。

## 12. 常见坑和建议

1. **勤存档**：接国王任务前、出远洋前、开战前。【网上攻略】
2. **远航时国王可能召见你**：如果你人在亚洲回不来，任务会被耽误。存档后再远航，被召见时读档留在欧洲。【网上攻略】
3. **不要早早得罪西班牙和奥斯曼**：开战以后对方港口会拒绝你进港，远航补给会很麻烦。【网上攻略】
4. **名望涨太快的副作用**：英文版有过"爵位还很低就被派去救公主"的情况。中文版按代码看，救公主只在公爵时出现，但保险起见按顺序升爵。
5. **20 年时间限制**：别在赌场和支线上耗太久，大约 1515 年前应该升到伯爵以上。
6. **钱存在皇宫账户里最安全**：舰队被击沉时身上的钱会损失，皇宫账户里的不会。

## 13. 快速通关（配合修改器）

本仓库的实时修改器（`trainer/`）可以在游戏运行时直接改数值：

| 想要的效果 | 修改器里的操作 |
|---|---|
| 钱永远花不完 | 金币改成 65535 并勾选"锁定" |
| 让国王召见 | 名望改成 **45000**（满足所有爵位门槛，见第 4 节表格） |
| 不用等 20 天才被召见 | 作弊开关："国王召见检查改为每天一次" |
| 国王任务秒完成 | 作弊开关："国王任务：接了任务回王宫就算完成" |
| 航行不用补给 | 作弊开关："航行不消耗粮食和水" |
| 海战必胜 | 作弊开关：炮击、白刃战两项 |
| 快速到港口 | 港口瞬移（瞬移后船是停着的，要"操作 → 起锚"才能开） |
| 船员不够 | 舰队表里直接改船员数（不要超过船的容量） |

**已验证可行的升爵路线**（一级一级升，剧情最稳）：
1. 作弊开关全部打开，名望改成 45000，金币锁在 65535。
2. 出港在海上走一天，回里斯本。
3. 进王宫接国王任务，**马上再跟国王说一次话**，任务完成，爵位 +1。
4. 重复第 2、3 步，直到公爵（从无爵位开始共 9 次）。
5. 公爵后国王派营救公主任务。这个任务不会自动完成：去酒馆打听 → 海上截击 → 带公主回里斯本见国王。

> 也可以直接把爵位改成 9（公爵）跳过升级，但这样剧情能否正常触发没有验证过。改之前先在教堂存一个档。
